Section 05

Project Scope and Context

This project is a master's thesis mission, conducted as the sole engineer responsible for the software and PTL hardware scope. The starting point was a client tender with no existing architecture, no codebase, and no prior implementation to build on at ATS.

The academic literature on integrated PTL-ASRS systems in industrial conveyor environments is limited. Existing published work addresses PTL optimisation in static, offline retail distribution contexts. The specific problem treated here — a fully custom-built system integrating WMS software, ASRS control, conveyor sequencing, and PTL stations in a live industrial environment — has no direct reference architecture in the literature. Design decisions were grounded in adjacent published work where applicable and reasoned from the operational constraints of the site otherwise.

The system is currently in implementation. Full production deployment is expected before the end of the mission in September 2026.
